# Children's Character Growth Quiz

This is a simple interactive web-based quiz designed to help children (or parents and educators) reflect on values like friendship, courage, hope, and growth mindset. After answering 10 multiple-choice questions, quiz takers receive book recommendations based on which topics they missed.

### ✅ Features
- 10 short multiple-choice questions
- No login required
- Only shows incorrect answers and recommended books (e.g., *Lumi the Light*, *Sometimes You Win…*, etc.)
- Built using plain HTML, CSS, and JavaScript
- No external dependencies

### 📚 Books Covered
- Lumi the Light Learns About Friendship
- Lumi the Light Learns to Hope
- Lumi the Light Learns to Shine
- Miraculous Pencil
- Sometimes You Win, Sometimes You Learn
- The Tuttle Twins Learn About the Law
- Who Moved My Cheese for Kids
